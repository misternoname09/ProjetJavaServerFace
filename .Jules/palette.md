## 2025-05-15 - Improving Accessibility and Form Validation in JSF
**Learning:** Legacy JSF applications often lack basic accessibility features like label associations and ARIA roles. Furthermore, small syntax errors (like dot vs colon in tags) and case-sensitivity in EL expressions can lead to broken functionality.
**Action:** Always verify label-input associations using `for`/`id`, ensure correct namespace usage for passthrough attributes, and double-check EL method names against Java source code.
