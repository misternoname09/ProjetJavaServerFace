## 2026-08-03 - [JSF and PrimeFaces Form Validation and Accessibility]
**Learning:** In PrimeFaces/JSF forms, connecting `p:outputLabel` using `for` with input field `id`s provides essential screen-reader accessibility by outputting native HTML `<label>` elements. Organizing this within a 3-column `p:panelGrid` alongside localized `<p:message>` targets delivers localized, accessible, and clean inline validation feedback. Additionally, JS confirmation dialogs inside XML attributes (like `onclick`) are highly vulnerable to string quoting syntax errors; adopting phrasing like "cet étudiant" instead of "l'étudiant" avoids single-quote escaping conflicts completely.
**Action:** Always wrap input forms in independent `<h:form>` tags, use 3-column `p:panelGrid` layouts with `for` associations, and use syntax-safe localized phrasing for client-side popups.
