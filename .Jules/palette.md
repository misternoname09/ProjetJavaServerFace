## 2025-05-15 - [JSF Accessibility and JavaScript Pitfalls]
**Learning:** In JavaServer Faces (JSF) applications using PrimeFaces, accessibility is often compromised by missing 'for' and 'id' associations on 'p:outputLabel' and input components. Additionally, JavaScript in attributes like 'onclick' (e.g., 'confirm()') can break if French text with single quotes is not properly escaped or wrapped in double quotes. Ensuring each interactive section is wrapped in a non-nested '<h:form>' is also critical for correct JSF lifecycle execution.
**Action:** Always verify that 'p:outputLabel' has a 'for' attribute matching the 'id' of its input. Escape single quotes in French JavaScript strings (e.g., l\'etudiant) or use double quotes for the entire attribute. Avoid nesting '<h:form>' tags and ensure every submit button has a parent form.
