## 2026-07-20 - [JSF and PrimeFaces Form Layout & Accessibility]
**Learning:** In JSF and PrimeFaces applications, nesting `<h:form>` tags causes silent lifecycle execution failures. Separating table operations and creation forms into independent sibling forms (`formListe` and `formAjout`) ensures correct lifecycle execution. Additionally, using `<h:panelGrid columns="3">` cleanly aligns `<p:outputLabel>` (which must explicitly map to inputs using the `for` attribute for screen reader compliance), the input field itself, and an inline `<p:message>` component to provide accessible, real-time validation feedback.
**Action:** Always verify form boundaries in legacy XHTML files to eliminate nested forms. When designing forms, structure them with a three-column layout, map labels to input IDs, and place inline message components immediately adjacent to each input.
