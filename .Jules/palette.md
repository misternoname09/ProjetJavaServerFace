## 2026-08-04 - [Single Quote Escaping and PrimeFaces Form Validation]
**Learning:** French accents and apostrophes (e.g. "l'étudiant") in JavaScript onclick attributes (like `confirm()`) within JSF elements cause single-quote syntax errors unless properly escaped. Using alternative French phrasing like "cet étudiant" elegantly avoids escaping issues entirely. Additionally, pairing `p:panelGrid columns="3"` with `p:outputLabel for="..."` and `p:message for="..."` enforces robust, accessible, and self-contained validation feedback layout in JSF forms.
**Action:** When designing or refactoring JSF/PrimeFaces forms, always leverage the 3-column panelGrid pattern for immediate, accessible validation feedback, and use static, non-conflicting phrasing in confirmation prompts to ensure cross-browser scripting safety.
