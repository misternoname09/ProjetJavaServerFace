## 2026-07-29 - Structuring Accessible PrimeFaces Forms in Legacy JSF Apps
**Learning:** In PrimeFaces, using h:panelGrid with columns="3" allows labels, input fields, and p:message validation to align perfectly. Coupling this with the 'for' attribute on p:outputLabel ensures screen-reader accessibility while required="true" triggers immediate validation feedback. Also, nesting forms in JSF is invalid and prevents form submission; separating tables and creation/edit forms into independent sibling form containers (e.g., formListe, formAjout) is essential.
**Action:** Always wrap independent JSF layout blocks in separate h:form tags, link p:outputLabel to inputs via 'for', and use p:message within a 3-column panelGrid instead of using <br/> or raw line breaks for alignment.
