## 2026-08-14 - Escaping Single Quotes in XHTML Confirmation Dialogs
**Learning:** In XHTML files (like JSF/Facelets pages), embedding javascript inline confirmation blocks such as `confirm('voulez-vous supprimer l\'etudiant')` causes JavaScript syntax errors because backslash escaping is not natively processed or recognized by XML/XHTML attributes. Standard single quotes within French text like `l'etudiant` prematurely close the JS string literal, rendering the action broken.
**Action:** Simplify phrasing to avoid single quotes altogether, such as using "cet étudiant" instead of "l'étudiant", or ensure correct escaping to avoid breaking inline scripts. Also, always add explicit `a:aria-label` passthrough attributes to confirm/delete buttons to improve screen reader experience.
