## 2025-05-15 - JSF/PrimeFaces Accessibility and Syntax Pitfalls
**Learning:** In legacy JSF projects, critical UX failures often stem from simple syntax errors (like `<h.form>` instead of `<h:form>`) or variable mismatches in data tables. Accessibility is frequently overlooked, particularly the association between labels and inputs which is crucial for both screen readers and clickability. Unescaped characters in inline JavaScript (e.g., single quotes in French text) also pose a common risk to interactive elements.
**Action:** Always verify JSF tag syntax (colons, not dots) and check that `p:dataTable` properties correctly reference the `var` attribute. Escaping single quotes in JavaScript strings is essential for French localization. Ensure every `p:outputLabel` has a `for` attribute pointing to an existing component `id`.
