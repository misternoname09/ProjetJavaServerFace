## 2026-07-02 - Legacy JSF Form Revitalization
**Learning:** Revitalizing legacy JSF/PrimeFaces interfaces requires a holistic approach: fixing functional bugs (broken iteration variables, malformed tags, JS syntax errors) is a prerequisite for meaningful UX and accessibility improvements like connected labels and ARIA support.
**Action:** Always verify Java bean method casing (e.g., PascalCase 'AddEtudiant') before fixing JSF 'action' attributes, as legacy projects often deviate from standard camelCase conventions.
