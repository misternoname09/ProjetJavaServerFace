## 2026-07-19 - Legacy JSF UI and Accessibility Optimization
**Learning:** Legacy JSF codebases often contain nested `<h:form>` structures (such as `<h.form>` syntax errors) and unescaped single quotes in JavaScript event handlers (like confirm boxes), which silently break form submission and execution. Explicitly separating forms into sibling blocks (`formListe` and `formAjout`), connecting labels to inputs using the `for` attribute on `p:outputLabel`, and adding HTML5 attributes like `a:aria-label` or `a:placeholder` via the JCP passthrough namespace successfully restores standard form behavior while maximizing screen reader accessibility and inline validation without requiring heavy style overrides.
**Action:** Always audit the page hierarchy for nested/malformed forms, escape JS handler single quotes, and use `a:aria-label` directly without XML escaping within double quotes to cleanly resolve validation and accessibility issues.
