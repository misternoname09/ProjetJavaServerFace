## 2026-07-27 - PrimeFaces Forms and Accessible Action Tables
**Learning:** In JSF and PrimeFaces environments, ensuring accessible form validation and interactive data grids requires clean separation of forms, explicit association of labels (using the `for` attribute and matching component `id`), and inline error messages using `<p:message>` aligned neatly in a three-column layout. When providing actions inside tabular data tables, standard screen readers struggle with generic action names (like "Modifier" or "Supprimer") unless descriptive row-specific tags like `a:aria-label="Modifier l'etudiant #{et.nom}"` are supplied.
**Action:** Always wrap independent forms in their own `<h:form>` tags with unique IDs, use `h:panelGrid columns="3"` to structure inputs, labels, and message tags, and use the passthrough namespace `xmlns:a="http://xmlns.jcp.org/jsf/passthrough"` to assign context-rich `a:aria-label` tags in row columns.
