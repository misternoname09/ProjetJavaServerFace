## 2026-11-05 - Delete Confirmation JS Escaping and Button Tooltips
**Learning:** In JSF/Facelets XHTML attributes, inline JavaScript confirm dialogs containing unescaped apostrophes (e.g., `'voulez-vous supprimer l'etudiant'`) break JavaScript syntax at runtime, silently failing or freezing user interaction upon clicking action buttons. Additionally, standard JSF action buttons and links natively support the `title` attribute for tooltips and screen reader descriptions without requiring extra passthrough attributes.
**Action:** Phrasing confirmation messages using demonstratives (e.g., `cet etudiant`) avoids single-quote string termination issues in JavaScript onclick handlers, and applying `title` attributes on action buttons enhances both mouse hover discoverability and accessibility.
