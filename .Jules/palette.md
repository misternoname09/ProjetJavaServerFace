## 2026-06-20 - Legacy JSF Form Improvement
**Learning:** When improving legacy JSF forms, prioritize fixing functional bugs (like invalid tag syntax and variable mismatches) that block UX improvements. Combining these with small accessibility touches (ARIA labels, proper confirmation dialogs) provides a more robust and compliant micro-UX enhancement.
**Action:** Always check for basic JSF lifecycle requirements (like non-nested forms and correct case sensitivity in method references) when performing even small UI adjustments in legacy Java EE environments.
