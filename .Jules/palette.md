## 2026-06-27 - Working with legacy JSF environments
**Learning:** Legacy JSF applications often contain structural syntax errors (e.g., nested forms, invalid tag separators) and functional bugs (e.g., variable mismatches) that block UX improvements.
**Action:** Perform a manual structural audit of XHTML files to fix functional and syntax blockers before applying micro-UX enhancements. Always ensure JSF-specific accessibility (e.g., label association via 'for'/'id') is implemented.
