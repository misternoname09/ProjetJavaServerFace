## 2026-08-05 - JSF/Facelets Component Accessibility and Inline Javascript Formatting
**Learning:** In legacy JSF/PrimeFaces environments, inline Javascript event handlers like `onclick` are prone to breaking due to unescaped single quotes (e.g., French phrasing like "l'étudiant"). Additionally, screen readers struggle to differentiate table row-specific actions (e.g., "modifier", "supprimer") without explicit context labels.
**Action:** Use French phrasing like "cet étudiant" to completely bypass single-quote escaping issues inside Javascript attributes, and employ the passthrough namespace `xmlns:a="http://xmlns.jcp.org/jsf/passthrough"` to assign dynamic screen-reader accessible labels using `a:aria-label` directly on JSF/PrimeFaces components without breaking legacy XML compilers.
