## 2026-07-30 - Accessible JSF/PrimeFaces Form-to-Validation Integration
**Learning:** Combining dynamic HTML5 passthrough attributes (like `a:aria-label` via `xmlns:a="http://xmlns.jcp.org/jsf/passthrough"`) with JSF's server-rendered dynamic data enables highly accessible actions within legacy PrimeFaces components. Furthermore, explicit association of form labels (`for` attribute) with inputs (`id` attribute) paired with matching `<p:message>` components in a 3-column `<p:panelGrid>` layout provides accessible inline validation feedback that is screen-reader friendly and visually unified.
**Action:** Use the passthrough namespace for HTML5 accessibility in JSF pages, explicitly declare associations for all inputs and labels, and keep forms cleanly separated without nesting to avoid lifecycle conflicts.
