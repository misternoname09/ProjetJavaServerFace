## 2026-08-07 - [Resolving JSF Table Variable Binding Mismatches and Escape Pitfalls]
**Learning:** Legacy PrimeFaces and standard JSF data tables often use `var` bindings that must exactly match nested cell references. Discrepancies between variables (e.g., mismatching `var="e"` with `#{et.nom}`) prevent data from rendering without throwing immediate server exceptions. Additionally, embedding standard JavaScript functions (such as `confirm()`) within tag attributes like `onclick` can result in broken UI pages if nested single quotes or unescaped characters are used inside the JS string.
**Action:** Always audit `var` definitions on tables to ensure they match internal cell expressions, and use clean, apostrophe-free text/French phrasing in JavaScript confirm dialogs (e.g. "Voulez-vous supprimer cet étudiant ?" instead of "Voulez-vous supprimer l'étudiant") to avoid escaping/syntax errors completely.
