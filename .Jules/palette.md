## 2026-08-09 - Overcoming Escaping Pitfalls and Nested Form Pitfalls in JSF and PrimeFaces
**Learning:** In legacy JSF projects using French localizations, string literals inside inline JS event handlers (like `onclick="confirm('l'etudiant')"` inside XHTML attributes) can trigger JS parse errors due to unescaped single quotes. Replacing the apostrophe with alternative phrasing like `cet étudiant` completely avoids quote-escaping and ensures clean rendering and seamless action execution. Additionally, separating independent data tables and creation forms into non-nested `<h:form>` siblings is mandatory to maintain stable lifecycle execution in JSF.
**Action:** Always audit inline JS confirm blocks in localizations for single-quote collisions, use gender-neutral/non-apostrophe phrasing in French where applicable, and isolate form contexts into distinct sibling forms with explicit `for`/`id` labels for screen reader compatibility.
